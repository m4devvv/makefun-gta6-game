Palmora Bay — an original open-world crime game that plays offline in a desktop browser. Explore a living 2D city on foot or behind the wheel, steal cars, outrun the police across five wanted levels, and finish three missions for $1,000. One self-contained `game/index.html` (canvas 2D, inline CSS/JS, zero external assets, zero network requests) with a HUD, minimap, start screen, pause, and localStorage save.

## Run it

```sh
cd game && python3 -m http.server 8000
```

Then open http://127.0.0.1:8000/index.html and press START GAME.
